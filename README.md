# Temperature_Logbook
Temperature Logbook: Record Current or Past Body Temperatures in °F with Colour-Coded Hazard Levels (Low, Fever, High fever), Flagged Gaps between Readings, Date Filters, Summary Stats and a Zoomable History Chart. Google Sign-In Syncs Records via Firebase; Guests Save On-Device. JSON Import/Export. https://prajwal250.github.io/Temperature_Logbook/
